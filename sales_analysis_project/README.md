📊 Sales Analysis Using Time Series & Category Charts
📌 Project Overview
This project performs sales data analysis using Python to visualize trends over time and compare sales across different categories.
The analysis includes time series charts, monthly and quarterly aggregation, category-wise comparison, and sales share visualization.
The project is created using Jupyter Notebook in VS Code and is suitable for academic submission, internship evaluation, and GitHub portfolio.


🎯 Objectives
•	Analyze sales trends over time
•	Perform monthly and quarterly sales aggregation
•	Compare sales across product categories
•	Visualize category-wise sales contribution
•	Save charts as images and summarize insights


🛠️ Tools & Technologies Used
•	Python
•	Pandas – data manipulation
•	Matplotlib – plotting charts
•	Seaborn – enhanced visualizations
•	Jupyter Notebook
•	VS Code
